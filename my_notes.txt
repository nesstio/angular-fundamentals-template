Subject из RxJS — это поток событий, в который можно вручную «пушить» значения (через .next()).
Переменная с суффиксом $ — по соглашению так называют Observable.

subscriptions: Subscription[] = [];
Массив активных подписок.

Каждую подписку добавляют сюда (this.subscriptions.push(...)), а в ngOnDestroy делают отписку 
(unsubscribe()), чтобы избежать утечек памяти

Разбор по шагам:

-this.searchTermByCharacters.pipe(...)
Берём поток значений, которые приходят из инпута (Subject).

-debounceTime(300)
Ждём 300 мс после последнего ввода. Если пользователь печатает быстро, запрос отправится только когда он остановится → меньше «спама» запросами.

-filter((term: string) => term.trim().length >= 3)
Пропускаем дальше только строки длиной 3+ символа. Если меньше — запрос не делаем.

-switchMap((term: string) => this.mockDataService.getCharacters(term))
На каждый валидный ввод вызываем API getCharacters.

-switchMap отменяет предыдущий запрос, если пользователь ввёл что-то новое. Это важно, чтобы результаты не «перепутались».

Берём два потока-флага:

getPlanetLoader() → true/false во время загрузки планет

Передаём этот массив в функцию areAllValuesTrue, которая вернёт true,

Сохраняем подписку в массив, чтобы потом отписаться в ngOnDestroy и

  Метод ngOnDestroy — хук жизненного цикла Angular, вызывается при уничтожении компонента.
Проходим по массиву this.subscriptions, где хранятся все подписки.

Вызываем unsubscribe() у каждой → останавливаем поток данных.

Это предотвращает утечки памяти и ошибки, когда компонент уже уничтожен, а данные продолжают приходить.

👉 Итог: метод аккуратно завершает все подписки при удалении компонента.
------------------

  areAllValuesTrue(elements: boolean[]): boolean {
    return elements.every((el) => el);
  }
  Эта вспомогательная функция проверяет, что все элементы массива — true.

Параметр: elements: boolean[] — массив булевых значений.

elements.every((el) => el) — метод every возвращает true, 
если коллбэк вернёт true для каждого элемента массива.

В итоге:

[true, true] → true

[true, false] → false

[] → true (особенность every — пустой массив всегда даёт true).

👉 В твоём коде эта функция нужна, чтобы из двух флагов загрузки 
(charactersLoader, planetLoader) сделать общий флаг isLoading.

What is a Stream
Поток — это, по сути, последовательность значений данных, 
изменяющихся с течением времени. Это может быть простое приращение чисел, 
выводимых каждые 6 секунд (0, 1, 2, 3, 4, 5), или координат, выводимых с течением времени,
 и даже значения данных, введенных в форму или текстов чата, 
 переданных через веб-сокеты или ответы API. Всё это представляет собой значения данных, 
 которые будут собираться с течением времени, отсюда и название «поток».

Observable как информационная рассылка. Информационная рассылка — это источник данных 
 (электронных писем), но пока вы не подпишетесь на неё, вы не будете получать никаких писем.
  После подписки на новостную рассылку вы начнёте получать поток писем 
  (то есть ровно шесть на изображении выше) в течение определённого периода времени.
   Вы будете получать письма, пока не отпишетесь от рассылки.

Observable  это источник данных, но он не генерирует данные, 
пока вы не подпишетесь. Поэтому мы говорим, что наблюдаемые объекты — ленивые. 
Подпишитесь на наблюдаемый объект, используя удачно названный 
метод subscribe(): myObservable.subscribe()

 Наконец, когда вам больше не нужны данные, вы можете отписаться, используя 
 метод unsubscribe(): myObservable.unsubscribe(). 
 Это важно для предотвращения утечек памяти. Обратите внимание, 
 что при использовании объекта Observable, созданного Angular, 
 отписываться не нужно, поскольку Angular автоматически обрабатывает отписку. 

 Subject это особый тип объекта Observable, позволяющий осуществлять 
 многоадресную передачу значений нескольким наблюдателям. В то время как 
 обычные наблюдатели являются одноадресными (каждый подписанный наблюдатель 
 владеет независимым выполнением объекта Observable), 
 субъекты являются многоадресными.
